PASSO 1 — Criar Port Forwarding

Abra:

PowerShell COMO ADMINISTRADOR

Muito importante.

PASSO 2 — Resetar Regras Antigas

Execute:

netsh interface portproxy reset
PASSO 3 — Criar Proxy TCP

Execute:

netsh interface portproxy add v4tov4 `
listenaddress=0.0.0.0 `
listenport=22 `
connectaddress=172.22.195.75 `
connectport=22

O Que Isso Faz
Windows escuta:
0.0.0.0:22

e encaminha para:

172.22.195.75:22
0.0.0.0 Novamente

Isso significa:

escutar em TODAS as interfaces

inclusive:

192.168.0.13
PASSO 4 — Abrir Firewall

Ainda no PowerShell ADMIN:

New-NetFirewallRule `
-DisplayName "WSL2 SSH" `
-Direction Inbound `
-Protocol TCP `
-LocalPort 22 `
-Action Allow


PASSO 5 — Verificar Regras

Execute:

netsh interface portproxy show all

Você deve ver algo tipo:

0.0.0.0    22    172.22.195.75    22
PASSO 6 — TESTE REAL

Agora, no Positivo:

ping 192.168.0.13

Isso DEVE responder.

Em termos de networking eu criei um TCP Forwarding / Port Forwarding
Criamos um servidor SSH dentro do WSL Linux.
Como o WSL2 roda em uma rede virtual NAT isolada pelo Hyper-V,
outros dispositivos da LAN não conseguem acessar diretamente o IP do WSL.

Então usamos o Windows Host como intermediário,
redirecionando a porta 22 do Windows para a porta 22 do WSL usando PortProxy.
